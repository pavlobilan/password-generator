# Генератор паролів

Статична сторінка генерації паролів. Пароль створюється в браузері через `crypto.getRandomValues`, на сервер нічого не передається.

## Можливості

- Великі й малі літери, цифри та спецсимволи вмикаються окремо.
- Читабельний набір без `I O Q l o 0 1`, як у Windows LAPS (`PasswordComplexity = 5`).
- Спецсимволи за замовчуванням: `!#%+@:=?*`. Набір можна змінити.
- Довільні символи можна виключити.
- Режим «кожен тип хоча б раз».
- Копіювання лише як plain text.

## Параметри URL

Сумісні з random.org (`?len=25&format=html&rnd=new`):

| Параметр | Значення | За замовчуванням |
|---|---|---|
| `len` | 4–128 | 25 |
| `upper`, `lower`, `digits`, `special` | `on` / `off` | `on` |
| `ambiguous` | `on` / `off` — читабельний набір | `on` |
| `each` | `on` / `off` — кожен тип хоча б раз | `on` |
| `symbols` | набір спецсимволів | `!#%+@:=?*` |
| `exclude` | символи, які не використовувати | — |

Приклад: `?len=16&special=off&exclude=xyz`

## Публікація на GitHub Pages

1. Завантажте `index.html` у корінь репозиторію.
2. Відкрийте **Settings → Pages**.
3. У **Source** виберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`.
4. Збережіть налаштування. Сторінка стане доступна за адресою `https://<user>.github.io/<repo>/`.
